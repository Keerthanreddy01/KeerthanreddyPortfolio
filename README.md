# Keerthan Reddy - Portfolio Website

A modern, dark-themed portfolio website inspired by Chronicle design, showcasing your professional profile, projects, and achievements.

## 🚀 Features

- **Modern Dark Theme**: Sleek, professional design with dark gray/black color palette
- **Responsive Design**: Fully responsive for desktop, tablet, and mobile devices
- **Smooth Animations**: Scroll-triggered animations and interactive elements
- **Professional Sections**:
  - Hero section with code window animation
  - About/Summary section
  - Skills showcase with widgets
  - Experience timeline
  - Projects grid with detailed cards
  - Achievements section
  - Contact/Footer

## 📁 Project Structure

```
portfolio/
├── index.html      # Main HTML structure
├── styles.css      # All styling and responsive design
├── script.js       # Interactive features and animations
└── README.md       # This file
```

## 🎨 Design Highlights

- **Color Scheme**: Dark theme with accent gradients
- **Typography**: Inter font family for modern, clean look
- **Layout**: Grid-based responsive layouts
- **Animations**: Fade-in effects, hover transitions, scroll animations

## 🛠️ Technologies Used

- HTML5
- CSS3 (with CSS Grid and Flexbox)
- Vanilla JavaScript
- Google Fonts (Inter)

## 📱 Sections

1. **Header**: Fixed navigation with smooth scroll
2. **Hero**: Eye-catching introduction with animated code window
3. **Trust Signals**: Badges and achievements
4. **About**: Professional summary and introduction
5. **Skills**: Technical skills with visual widgets
6. **Experience**: Timeline of professional roles
7. **Projects**: Featured projects with details
8. **Achievements**: Hackathons, certifications, and accomplishments
9. **Footer**: Contact information and links

## 🚀 Getting Started

1. Open `index.html` in a web browser
2. No build process required - it's a static website
3. Customize content in `index.html` as needed
4. Modify colors and styling in `styles.css`
5. Add more interactivity in `script.js`

## ✨ Customization

### Update Your Information

Edit the content in `index.html`:
- Personal details in the hero section
- Experience and projects
- Skills and achievements
- Contact information in the footer

### Change Colors

Modify CSS variables in `styles.css`:
```css
:root {
    --bg-primary: #0a0a0a;
    --bg-secondary: #141414;
    --accent: #6366f1;
    /* ... */
}
```

### Add More Sections

Simply add new sections following the existing pattern in `index.html` and style them in `styles.css`.
